# P13 — Menu e settimana

Aggiornare Code.gs, DriveDocs.gs (conservando ROOT_FOLDER_ID reale) e Index.html. Pubblicare Nuova versione dal deployment esistente, poi ricaricare /exec. Il badge in fondo al menu indica P13. Non eseguire setup o migrazioni.

Controllare icone, aprire Settimana e checkup e annotare il primo getState: le misure ora distinguono voci, estratti, file e dati comuni. Il ritorno alla vista in cache resta locale. I miglioramenti riducono le chiamate Sheets; non eliminano il costo di invocazione Apps Script e vanno misurati sul cloud.
